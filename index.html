01 · 선정 모델 티징 콘텐츠 원본

모델 티징 가이드

업로드11/25–11/27 이내 길이~15초 목표 반응“이게 무슨 프로젝트야?”
콘텐츠 콘셉트
성수에서 모델 모집하길래 지원했는데… 나 진짜 모델 됐어!

촬영 가이드

권장 영상 길이~15초
도입부서울의 라이프스타일과 패션을 이색적으로 보여주는 틈결 Fashion in Seoul 프로젝트 모델 발탁 안내
제품 노출파우치를 팔목에 착용하거나 배경에 자연스럽게 배치
촬영 무드감도 높은 패션 콘텐츠, 일상적인 분위기
제품 소개상세 설명 없이 자연스럽게 노출
마무리“서울의 라이프스타일과 패션을 이색적으로 즐길 수 있는 Fashion in Seoul 프로젝트”
12월 4일 틈결 플래그십 스토어에서 공개되는 프로젝트 암시
필수 태그@teumgyul_official

멘트 타입 (택 1)

TYPE A · 친구에게 자랑하는 느낌
“성수에서 모델 모집하길래 그냥 지원했거든요? 지원 경쟁율이 지금 80:1도 넘었다는데… 나 모델 됐어~~!”
TYPE B · 호기심을 유발하는 콘텐츠
“제가 최근에 공유한 모델 선정 현수막 기억나세요? 저 그거 지원했는데 진짜 모델 됐어요.”

이렇게 해 주세요 초안

  • 프로젝트 내용은 다 밝히지 말고 궁금증을 남겨 주세요.
  • 12월 4일, 성수 플래그십 스토어 두 가지 정보는 꼭 언급해 주세요.
  • 파우치는 손목이나 배경에서 한 번 이상 보이게 해 주세요.

피해 주세요 초안

  • 제품 기능·가격 등 상세 설명
  • 제품을 정면으로 들고 소개하는 광고형 컷
  • 공개 전 프로젝트 세부 내용 언급

02 · 오프라인 방문 콘텐츠 초안

오프라인 방문 가이드

업로드12/4 오픈 이후 · 기간 확정 필요 길이~30초 (권장안) 목표 반응“여기는 꼭 가봐야겠다.”
콘텐츠 콘셉트
내가 모델로 참여한 프로젝트가 드디어 공개됐어요. 성수 틈결 플래그십 스토어 다녀왔어요!

촬영 가이드

권장 영상 길이~30초
도입부스토어 외관 또는 입구 컷으로 시작. 티징 콘텐츠에서 예고한 Fashion in Seoul 프로젝트가 공개된 현장임을 알려 주세요.
매장 경험매장 동선을 따라 둘러보며 성수에서만 할 수 있는 쇼핑 경험을 보여 주세요. 본인이 모델로 참여한 프로젝트 비주얼 앞 컷은 꼭 넣어 주세요.
제품 노출매장에서 마음에 든 아이템을 직접 착용·피팅하는 장면. 파우치 등 대표 아이템이 자연스럽게 보이도록.
촬영 무드감도 높은 패션 콘텐츠, 실제로 놀러 온 듯한 브이로그 톤
제품 소개상세 설명보다 “이런 걸 볼 수 있다” 수준의 가벼운 소개
마무리“성수 틈결 플래그십 스토어에서 Fashion in Seoul 프로젝트를 직접 만나보세요” 등 방문 유도 멘트
필수 태그@teumgyul_official + 위치 태그 (틈결 플래그십 스토어)

꼭 담아야 할 장면

  • 스토어 외관·간판 (어디인지 알 수 있게)
  • 본인이 참여한 Fashion in Seoul 프로젝트 비주얼
  • 매장 내부 분위기가 보이는 와이드 컷
  • 아이템 착용·피팅 컷 1개 이상
  • 방문 유도 멘트가 들어간 엔딩 컷

멘트 타입 (택 1)

TYPE A · 현장 브이로그
“제가 모델로 참여한 프로젝트가 오늘 성수에서 공개됐어요! 같이 구경 가볼까요?”
도착 → 둘러보기 → 착용 → 엔딩 순서로 자연스럽게
TYPE B · 성수 핫플 추천
“성수 가면 여기는 꼭 들러보세요. 서울 패션을 이렇게 보여주는 곳은 처음이에요.”
추천 포인트 2–3개를 빠르게 컷 전환
확인 필요: 업로드 기간, 매장 주소·운영 시간, 촬영 가능 구역, 현장 이벤트 유무

03 · 상품 시딩 콘텐츠 초안

상품 시딩 가이드

업로드기간 확정 필요 길이~30초 (권장안) 목표 반응“이건 나도 사고 싶다.”
콘텐츠 콘셉트
요즘 제일 손이 가는 아이템 발견했어요. 이건 진짜 매일 들고 다녀요.

촬영 가이드

권장 영상 길이~30초
도입부첫 3초 안에 제품이 보이게 시작. 언박싱 또는 착용한 모습으로 시선을 잡아 주세요.
제품 노출디테일 클로즈업 + 실제 코디에 매치한 전신 컷을 함께
촬영 무드감도 높은 패션 콘텐츠, 데일리로 쓰는 모습
제품 소개내가 좋았던 포인트 2–3개를 본인 말로 (디자인, 소재, 활용도 등). 핵심 소구점은 브랜드 전달 내용 기준.
마무리구매처 안내 (성수 틈결 플래그십 스토어 / 온라인 채널)
필수 태그@teumgyul_official + 제품 태그

멘트 타입 (택 1)

TYPE A · 데일리 코디형
“요즘 출근할 때도, 놀러 갈 때도 이거 하나로 끝내요. 오늘 코디 같이 보실래요?”
2–3가지 코디에 매치하며 활용도 강조
TYPE B · 디테일 리뷰형
“처음 보자마자 이건 사야겠다 싶었던 이유, 디테일 보여드릴게요.”
클로즈업 위주로 포인트를 하나씩

이렇게 해 주세요

  • 실제로 사용하는 장면 위주로
  • 본인 스타일에 맞춘 코디
  • 구매처를 엔딩에 명확히

피해 주세요

  • 확인되지 않은 기능·효과 표현
  • 타 브랜드 제품과 비교·비하
  • 광고 표기 누락
확인 필요: 시딩 제품 목록, 제품별 핵심 소구점, 업로드 기간, 온라인 구매 링크·할인 코드 유무
